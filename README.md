# Подключаем к Яндекс.Алисе другой ИИ: ChatGPT, Gemini, Claude, Grok, DeepSeek, Qwen

Простой и быстрый скрипт на чистом PHP, который позволяет подключить к вашей умной колонке с **Алисой** любую современную нейросеть (через **OpenRouter**, **OpenAI** или локальный **Ollama**).

Без сложных фреймворков, баз данных и платных серверов — работает даже на самом обычном PHP-хостинге или локальном компьютере.

---

## ✨ Что умеет этот проект

* **Любая нейросеть внутри Алисы**: переключайтесь между ChatGPT, Claude, Gemini, DeepSeek, Grok или бесплатными моделями на OpenRouter, просто поменяв одну строчку в `.env`.
* **Укладывается в жесткий лимит Яндекса (3–4 секунды)**:
  * Отключает долгие «раздумья» модели (`REASONING=OFF`), чтобы ответ приходил за 1–2 секунды.
  * Ограничивает длину ответа (`AI_MAX_TOKENS`) и просит ИИ отвечать кратко и разговорно (`SYSTEM_PROMPT`).
  * Убирает спецсимволы (`*`, `#`, `` ` ``), чтобы Алиса не читала их вслух.
* **Помнит контекст беседы**: хранит последние 10 сообщений диалога, привязываясь к `session_id` вашей колонки.
* **Защита от чужих (`SECRET_KEY`)**: никто посторонний не сможет подключиться к вашему вебхуку и тратить ваш баланс.
* **Работает «из коробки»**: не требует установки библиотек через Composer — достаточно скопировать файлы на сервер.

---

## 📋 Что понадобится

1. **Аккаунт на [OpenRouter.ai](https://openrouter.ai/)** (или OpenAI) — чтобы получить API-ключ (`AI_API_KEY`). На OpenRouter доступны сотни моделей (включая бесплатные) и не нужен зарубежный IP.
2. **Хостинг или сервер с PHP 8.1+** и HTTPS-доменом (либо локальный компьютер + бесплатный туннель `ngrok` / `cloudflared`).

## 🚀 Установка и настройка за 3 шага

### Шаг 1. Скачайте проект и создайте файл настроек `.env`

Скопируйте файлы проекта на ваш сервер или компьютер и создайте файл `.env` из шаблона `.env.example`:

```bash
cp .env.example .env
```

Откройте файл `.env` и заполните свои данные:

```ini
# 1. Ваш API-ключ (например, с сайта https://openrouter.ai/keys)
AI_API_KEY=sk-or-v1-ваш_ключ

# 2. Секретное слово для защиты вебхука от чужих подключений
# Придумайте любой пароль без пробелов (например: my_secret_123)
SECRET_KEY=my_secret_123

# 3. Адрес API провайдера
# Для OpenRouter (рекомендуется):
API_BASE_URL=https://openrouter.ai/api/v1
# Для прямого OpenAI:
# API_BASE_URL=https://api.openai.com/v1
# Для локального Ollama:
# API_BASE_URL=http://localhost:11434/v1

# 4. Модель нейросети (список моделей: https://openrouter.ai/models)
AI_MODEL=openai/gpt-4o-mini

# 5. Настройки скорости (важно для лимита Алисы в 3-4 секунды!)
AI_MAX_TOKENS=400
REASONING=OFF

# 6. Характер и стиль ответов ИИ
SYSTEM_PROMPT="Ты голосовой ИИ-помощник, работаешь в умной колонке Алиса и говоришь голосом Алисы. Отвечай кратко, по сути, разговорным языком (1-3 предложения), без списков и без markdown-разметки."
```

---

### Шаг 2. Запустите вебхук

#### Вариант А: На своем хостинге или VPS-сервере
Просто положите файлы в папку вашего сайта (например, `https://alice.example.com/`). Ничего дополнительно устанавливать не нужно!
> **Важно для безопасности:** убедитесь, что веб-сервер (Nginx/Apache) закрывает доступ к файлу `.env` из браузера.

#### Вариант Б: На своем компьютере (для теста без хостинга)
1. Запустите встроенный PHP-сервер в папке проекта:
   ```bash
   php -S 0.0.0.0:8000 index.php
   ```
2. Откройте второе окно терминала и запустите бесплатный HTTPS-туннель:
   ```bash
   # Через cloudflared:
   cloudflared tunnel --url http://localhost:8000

   # Или через ngrok:
   ngrok http 8000
   ```
3. Скопируйте полученную `https://...` ссылку.

---

### Шаг 3. Подключите навык в Яндекс.Диалогах

1. Перейдите в [Консоль Яндекс.Диалогов](https://dialogs.yandex.ru/developer) и нажмите **«Создать диалог»** → **«Навык в Алисе»**.
2. Заполните основные поля:
   * **Название навыка**: например, `Умный помощник`
   * **Активационное имя**: выберите из предложенных вариантов
   * **Backend** → выберите **Webhook URL** и укажите ваш адрес вместе с вашим `SECRET_KEY` из `.env`:
     ```text
     https://ваш-домен.ru/?key=my_secret_123
     ```
     *(если вы оставили `SECRET_KEY=YOUR_SEKCRET_WORD` по умолчанию, параметр `?key=...` можно не добавлять).*
3. Выберите **Доступ**: **«Приватный»** (чтобы навык работал только на ваших устройствах под вашим Яндекс ID и не требовал долгой модерации).
4. Нажмите **«Сохранить»**, перейдите на вкладку **«Тестирование»** и напишите `Привет`!
5. Чтобы навык заработал на вашей домашней колонке Яндекс.Станция, на вкладке «Общие сведения» нажмите **«Опубликовать»** (для приватного навыка публикация происходит автоматически за пару минут). После этого просто скажите своей колонке:
   > *«Алиса, запусти навык [Ваше название навыка]»*

## ❓ Частые вопросы (FAQ)

### 1. Алиса говорит: «Извините, навык не отвечает»
Яндекс ждет ответ от вашего сервера максимум **3–4 секунды**. Если нейросеть думает дольше, Яндекс обрывает соединение.
**Как исправить:**
* Проверьте, что в `.env` стоит `REASONING=OFF` и `AI_MAX_TOKENS=400`.
* Выберите более быструю модель (например, `openai/gpt-4o-mini`, `google/gemini-2.5-flash` или `openai/gpt-6-luna`).

### 2. Как сменить нейросеть?
Откройте `.env`, поменяйте значение `AI_MODEL=...` на любую другую модель с сайта [OpenRouter Models](https://openrouter.ai/models) и сохраните файл. Перезагружать ничего не нужно — изменения применяются мгновенно.

### 3. Нужен ли прокси для работы из РФ?
* Если используете **OpenRouter** (`https://openrouter.ai/api/v1`) — прокси обычно **не нужен**, сервис доступен напрямую.
* Если используете прямой **OpenAI** (`https://api.openai.com/v1`) с российского сервера — раскомментируйте в `.env` строчку `HTTP_PROXY=http://127.0.0.1:10809` (или укажите адрес вашего `socks5://` / `http://` прокси).
